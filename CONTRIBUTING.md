# Cómo contribuir / Contributing

Este repositorio agrupa ejercicios, plantillas y mini-proyectos. Si deseas proponer cambios en documentación o añadir un mini‑proyecto, sigue las directrices que se listan a continuación para facilitar la revisión.

## Guía rápida

- Usar `docs/PROJECT_README_TEMPLATE.md` al añadir un nuevo proyecto/mini-app en `proyectos/`.
- Se recomiendan mensajes de commit concisos en inglés (una línea, mayúscula inicial).
- Para cambios de código significativos, abrir un Pull Request que describa el propósito, los archivos modificados y cómo probar los cambios.

## Requisitos mínimos para añadir un proyecto

1. Carpeta dentro de `proyectos/` con nombre claro.
2. `README.md` basado en `docs/PROJECT_README_TEMPLATE.md`.
3. `Dockerfile` o instrucciones claras de ejecución.
4. Tests básicos (si aplica) y comando para ejecutar los tests.
5. (Opcional) Workflow de CI en `.github/workflows/` que ejecute tests.

Para dudas o coordinación sobre cambios amplios, contactar al autor.
