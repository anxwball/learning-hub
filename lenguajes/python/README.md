# Python

## Descripción

Contiene ejercicios prácticos y material estructurado para el estudio y la ampliación de contenido en Python.

## Ubicación

`lenguajes/python`

## Estado

- Módulo activo con la serie de 100 ejercicios disponible.
- Laboratorios de `freeCodeCamp` incorporados en `freecodecamp_labs/`.
- Preparado para incorporar pruebas automatizadas y nuevos contenidos.

## Estructura

- `100_ejercicios/`: colección de ejercicios basada en la serie
  "Entrenamiento Python con 100 Ejercicios".
- `freecodecamp_labs/`: laboratorios prácticos de la ruta de Python en freeCodeCamp.
- `tests/`: carpeta reservada para pruebas automatizadas.
- `pyproject.toml`: configuración base del proyecto Python.
- `uv.lock`: archivo de bloqueo de dependencias.
- `.venv/`: entorno virtual local del módulo.

## Ejecución de ejercicios

Desde la raíz del repositorio:

```bash
python lenguajes/python/100_ejercicios/Ejercicio_1.py
```

Si usas `uv`:

```bash
uv run python lenguajes/python/100_ejercicios/Ejercicio_1.py
```

Ejemplo de laboratorio freeCodeCamp:

```bash
python lenguajes/python/freecodecamp_labs/travel_weather_planner/main.py
```
