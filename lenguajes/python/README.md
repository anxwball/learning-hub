# Python

## Descripción

Módulo de aprendizaje en Python con ejercicios prácticos y estructura para
seguir ampliando contenido.

## Ubicación

`lenguajes/python`

## Estado

- Módulo activo con la serie de 100 ejercicios disponible.
- Base preparada para ampliar pruebas automatizadas y nuevos contenidos.

## Estructura

- `100_ejercicios/`: colección de ejercicios basada en la serie
  "Entrenamiento Python con 100 Ejercicios".
- `tests/`: carpeta reservada para pruebas automatizadas.
- `pyproject.toml`: configuración base del proyecto Python.
- `uv.lock`: archivo de bloqueo de dependencias.
- `.venv/`: entorno virtual local del módulo.

## Ejecución de ejercicios

Desde la raíz del repositorio:

```bash
python lenguajes/python/100_ejercicios/Ejercicio_1.py
```

Si usas `uv`:

```bash
uv run python lenguajes/python/100_ejercicios/Ejercicio_1.py
```
