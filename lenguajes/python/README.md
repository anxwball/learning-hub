# Python

## Descripción

Contiene ejercicios prácticos y material estructurado para estudiar, ampliar y consolidar contenido en Python.

## Estado actual

- El módulo está activo con una serie de 100 ejercicios ya disponible.
- Los laboratorios de freeCodeCamp están agrupados en `freecodecamp_labs/`.
- La base del módulo está configurada con `pyproject.toml`, `uv.lock` y `.python-version` local.
- El contenido está orientado a crecimiento progresivo y futura cobertura de pruebas.

## Estructura

- `100_ejercicios/`: colección de ejercicios basada en la serie "Entrenamiento Python con 100 Ejercicios".
- `freecodecamp_labs/`: laboratorios prácticos de la ruta de Python en freeCodeCamp.
- `pyproject.toml`: configuración base del proyecto Python.
- `uv.lock`: archivo de bloqueo de dependencias.
- `.gitignore`: reglas locales del módulo Python.
- `.python-version`: versión de Python usada por el módulo.

## Ejecución de ejercicios

Desde la raíz del repositorio:

```bash
python lenguajes/python/100_ejercicios/Ejercicio_1.py
```

Si usas `uv`:

```bash
uv run python lenguajes/python/100_ejercicios/Ejercicio_1.py
```

Ejemplos de laboratorios freeCodeCamp:

```bash
python lenguajes/python/freecodecamp_labs/travel_weather_planner/main.py
python lenguajes/python/freecodecamp_labs/rpg_character/main.py
python lenguajes/python/freecodecamp_labs/number_pattern_generator/main.py
python lenguajes/python/freecodecamp_labs/apply_discount_func/main.py
python lenguajes/python/freecodecamp_labs/user_config_manager/main.py
```
