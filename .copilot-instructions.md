# learning-hub: Standardization & Normalization Guide

You are assisting with the **learning-hub** repository. Your role: normalize Python files, README.md files, and documentation to match project standards.

## Key Standards for This Workspace

### 1. Python Module Structure

**Every Python file MUST include:**

1. **Module docstring (first lines)** with EXACT sections:
   - `Problema`: [concise problem description]
   - `Fuente`: [source/course name]
   - `Plataforma`: [platform, URL if applicable]
   - `Etiquetas`: [comma-separated keywords]
   - `Fecha`: YYYY-MM-DD
   - `Estado`: resuelto | en-progreso | pendiente
   - `Enfoque`: [2-3 bullet points on approach/strategy]
   - `Complejidad`: Time O(?) | Space O(?) [with brief explanation]
   - `Casos límite`: [edge cases and how they're handled]
   - `Casos de uso`: [2-3 practical/educational uses]
   - `Revisión`: [historical changelog, first entry = "YYYY-MM-DD: Initial documentation and standardization"]

2. **Type hints** on ALL functions: arguments + return type
   ```python
   def add_setting(settings: Dict[str, str], setting_tuple: Tuple[str, str]) -> str:
   ```

3. **PEP 257 docstrings** for module and every function:
   - Function docstring: brief description, optional extended paragraph, Args, Returns sections

4. **Guard clause** at end:
   ```python
   if __name__ == "__main__":
       main()
   ```

5. **Naming conventions**: snake_case, descriptive names
6. **PEP 8**: max 79 characters/line, 4-space indentation
7. **Main entry point**: `def main() -> None:` for all executable logic

### 3. Documentation Sync

When updating `main.py`:
- Update `Fecha` if significant change
- Update `Estado` if it changed
- Add line to `Revisión` section
- Update parent README's "Última actualización"

When updating README:
- Update "Última actualización" to today's date (YYYY-MM-DD)
- If new exercise, add entry to parent README's exercise list

- Format: One line, capitalize first letter

## Example: Good vs. Bad

### ❌ BAD (Before)
```python
test_settings = {'theme': 'light'}

def add_setting(dictionary, setting_tuple):
    key, value = setting_tuple
    if key in dictionary:
        return "error"
    else:
        dictionary[key] = value
        return "success"

add_setting({'a': 'b'}, ('c', 'd'))
```

### ✅ GOOD (After)
```python
"""
Problema  : Manage user configuration settings
Fuente    : FreeCodeCamp Python Certification
...
"""

def add_setting(settings: Dict[str, str], setting_tuple: Tuple[str, str]) -> str:
    """Add a new setting to user configuration.

    Validates that the key doesn't already exist.

    Args:
        settings: Current settings dictionary
        setting_tuple: (key, value) tuple to add

    Returns:
        Success or error message
    """
    key, value = setting_tuple
    if key in settings:
        return f"Setting '{key}' already exists!"
    else:
        settings[key] = value
        return f"Setting '{key}' added successfully!"

if __name__ == "__main__":
    main()
```
