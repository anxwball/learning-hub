# Mi Learning Hub Personal

Repositorio personal de aprendizaje. Reúne mis ejercicios, notas y
recursos. No está pensado para uso externo ni para contribuciones de
terceros.

## Estructura

Carpetas en la raíz del proyecto:

- `.github/`: configuración de automatizaciones y flujos de trabajo de GitHub
    (por ejemplo, Actions o plantillas).
- `.vscode/`: ajustes locales del espacio de trabajo para Visual Studio Code.
- `backend/`: contenidos y prácticas de desarrollo backend (APIs,
    autenticación, bases de datos y FastAPI).
- `ciberseguridad/`: apuntes y ejercicios relacionados con seguridad
    informática.
- `cloud/`: material de aprendizaje sobre servicios en la nube (actualmente,
    contenido de AWS).
- `cursos/`: notas, ejercicios y recursos derivados de cursos.
- `diseno-sistemas/`: conceptos de arquitectura, diseño técnico y casos de
    estudio.
- `estructuras-datos/`: teoría y ejercicios de estructuras de datos y técnicas
    relacionadas.
- `frontend/`: contenidos y prácticas de desarrollo frontend (CSS y React).
- `lenguajes/`: ejercicios y ejemplos organizados por lenguaje de
    programación.
- `proyectos/`: proyectos prácticos e integradores.
- `recursos/`: recopilación de materiales de apoyo (canales, cursos, libros,
    plataformas). La plantilla para encabezados de ejercicios se encuentra en
    `recursos/ENCABEZADO_EJERCICIOS.md`.
- `redes/`: apuntes y prácticas de redes de computadoras.
- `sistemas-operativos/`: conceptos y material de estudio sobre sistemas
    operativos.
